# W5500 第三阶段：MQTT 通信应用 (03_应用层逻辑实现_连接与订阅)

## 1. 定义连接参数
在 `BSP/mqtt_app.c` 中定义 MQTT Broker 的连接参数。建议使用公共测试服务器进行验证。

```c
// Broker 配置
uint8_t target_ip[4] = {116, 62, 226, 174}; // broker.emqx.io
uint16_t target_port = 1883;

// Topic 定义
char* sub_topic = "w5500/control"; // W5500 订阅此主题接收指令
char* pub_topic = "w5500/status";  // W5500 发布此主题反馈状态
```

---

## 2. 步骤 A：网络层与客户端初始化
1.  **实例化对象**：
    ```c
    Network n;
    MQTTClient c;
    ```
2.  **绑定 Socket**：
    ```c
    NewNetwork(&n, MQTT_SOCKET); // 绑定 W5500 Socket 0
    ConnectNetwork(&n, target_ip, target_port); // TCP 握手
    ```
3.  **初始化 MQTT 客户端**：
    ```c
    MQTTClientInit(&c, &n, 1000, tx_buf, BUF_SIZE, rx_buf, BUF_SIZE);
    ```

---

## 3. 步骤 B：MQTT 协议握手 (Connect)
配置 ClientID 和 Keep-alive 间隔。

```c
MQTTPacket_connectData data = MQTTPacket_connectData_initializer;
data.willFlag = 0;
data.MQTTVersion = 3;
data.clientID.cstring = "W5500_STM32_Test"; // 必须唯一
data.keepAliveInterval = 60; // 60秒心跳
data.cleansession = 1;

if (MQTTConnect(&c, &data) == SUCCESS) {
    printf("MQTT Connected!\r\n");
    // 成功后立即订阅
    MQTTSubscribe(&c, sub_topic, QOS0, messageArrived);
}
```

---

## 4. 步骤 C：心跳维护 (MQTTYield)
MQTT 需要在 `main` 循环中定期调用 `MQTTYield` 来维持心跳和处理收包。

```c
while (1) {
    MQTTYield(&c, 100); // 100ms 处理一次 MQTT 事务
}
```
