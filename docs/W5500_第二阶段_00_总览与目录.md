# W5500 第二阶段（Socket API 实战）：总览与目录

阶段目标：在不引入 LwIP 的前提下，只用 WIZnet ioLibrary 的 `socket.h` API，把 UDP/TCP 通信跑通，并形成可复用的“socket 状态机”写法。

完成本阶段后，你应该能做到：
- UDP：板子能收能发（回显/上报）
- TCP：板子能做 Server（监听端口）与 Client（主动连接）
- Wireshark 能抓到 UDP/TCP 的收发，能定位常见问题（端口/防火墙/状态机/断线重连）

本阶段参考代码（WIZnet 官方 loopback 示例，建议边看边抄结构）：
- [loopback.c](file:///i:/AI/w5500/ioLibrary_Driver/Application/loopback/loopback.c#L17-L220)
