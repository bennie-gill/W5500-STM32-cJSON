# W5500 第一阶段 Step 7：阶段一验收清单（拿来就用）

目标：把“阶段一是否完成”变成一张清单。每次你改 SPI 频率、改网线、改网参，都可以按清单快速回归。

## 1. 硬件层验收

- 供电稳定（3.3V）且上电不掉压
- 插网线后 LINK 灯常亮（或至少 PHYLINK=1）
- MISO/MOSI/SCK/CS 连接无松动

## 2. MCU 外设验收（SPI/GPIO）

- SPI：Mode0（CPOL=0，CPHA=0），8bit，MSB First，NSS=Soft
- CS：GPIO 输出，默认高；事务期间拉低

参考代码：
- SPI1 配置：[spi.c](file:///i:/AI/w5500/Core/Src/spi.c#L30-L60)
- CS 配置：[gpio.c](file:///i:/AI/w5500/Core/Src/gpio.c#L52-L61)

## 3. W5500 ioLibrary 移植验收（回调是否生效）

- 已注册 CS/SPI/临界区回调
- `wizchip_init()` 执行完成

参考代码：
- [bsp_w5500.c](file:///i:/AI/w5500/BSP/bsp_w5500.c#L40-L58)

## 4. 寄存器级验收（必须达到）

- `VERSIONR == 0x04`
- `PHYLINK == 1`
- `MR` 未开启 PingBlock（`MR & 0x10 == 0`）

你可以直接看串口自检输出（`w5500_dump()`）：
- [bsp_w5500.c](file:///i:/AI/w5500/BSP/bsp_w5500.c#L60-L77)

## 5. 网络参数验收（静态 IP）

- 串口打印：MAC/IP/SN/GW 与 `network_init()` 写入一致
- PC 能 ping 通 `192.168.227.88`
- `arp -a` 能看到板子 IP 对应真实 MAC

PC 命令：

```powershell
ping 192.168.227.88
arp -a | findstr 192.168.227.88
```

多网卡时强制走指定接口：

```powershell
ping -S <你的以太网IPv4> 192.168.227.88
```

## 6. 抓包验收（可选但推荐）

Wireshark 过滤：
- `arp`
- `icmp`

验收：
- ARP Request/Reply 成对出现
- ICMP Echo Request/Reply 成对出现

## 7. 逻辑分析仪验收（可选但非常建议）

抓 `getVERSIONR()` 的 SPI：
- MOSI 头 3 字节：`00 39 00`
- MISO 返回：`04`

参考说明：
- [W5500_第一阶段_06_逻辑分析仪对齐SPI波形.md](file:///i:/AI/w5500/docs/W5500_%E7%AC%AC%E4%B8%80%E9%98%B6%E6%AE%B5_06_%E9%80%BB%E8%BE%91%E5%88%86%E6%9E%90%E4%BB%AA%E5%AF%B9%E9%BD%90SPI%E6%B3%A2%E5%BD%A2.md)

## 8. 阶段一完成判定

当你满足以下三条，就可以进入第二阶段（UDP/TCP Socket）：
- `VERSIONR=0x04` 稳定可重复
- `PHYLINK=1` 且 PC 能稳定 ping 通
- `arp -a` 能学到正确 MAC
