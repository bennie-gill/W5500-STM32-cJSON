# W5500 第三阶段：MQTT 通信应用 (02_接口层移植与定时器适配)

## 1. 为什么需要移植接口层？
MQTT 协议需要处理 **Keep-alive (心跳)** 和 **超时等待**。WIZnet 默认的接口层 (`mqtt_interface.c`) 通常使用自定义计数器，但在 STM32 环境下，我们可以直接使用系统自带的 `HAL_GetTick()` 来简化移植，无需手动在定时器中断中累加。

---

## 2. 步骤 A：使用 HAL_GetTick() 适配定时器
相比于在 `SysTick_Handler` 中注册回调，直接使用 HAL 库提供的毫秒级计时器 `HAL_GetTick()` 更加可靠且代码更整洁。

在 `mqtt_interface.c` 中，我们重写了 Timer 相关的函数：

```c
/* mqtt_interface.c */
char TimerIsExpired(Timer *timer) {
  uint32_t now = HAL_GetTick();
  return (now >= timer->end_time);
}

void TimerCountdownMS(Timer *timer, unsigned int timeout) {
  timer->end_time = HAL_GetTick() + timeout;
}

void TimerCountdown(Timer *timer, unsigned int timeout) {
  timer->end_time = HAL_GetTick() + (timeout * 1000);
}

int TimerLeftMS(Timer *timer) {
  uint32_t now = HAL_GetTick();
  if (now >= timer->end_time) return 0;
  return timer->end_time - now;
}
```

## 3. 步骤 B：重构非阻塞读写函数
我们需要在 `mqtt_interface.c` 中实现带有超时的读写，确保 MQTT 报文在网络波动时能完整接收。

### 3.1 修改 `w5x00_read`
```c
int w5x00_read(Network* n, unsigned char* buffer, int len, int timeout) {
    uint32_t start_tick = HAL_GetTick();
    int recv_len = 0;
    while (recv_len < len) {
        int ret = recv(n->my_socket, buffer + recv_len, len - recv_len);
        if (ret > 0) {
            recv_len += ret;
        } else if (ret != SOCK_BUSY && ret < 0) {
            return ret; // 通信错误
        }
        if ((HAL_GetTick() - start_tick) > timeout) break; // 超时退出
    }
    return recv_len;
}
```

## 4. 步骤 C：主循环中的 MQTTYield
MQTT 不需要中断触发，而是通过在 `main` 循环中持续调用 `MQTTYield` 来维持心跳和处理后台任务。

```c
/* main.c */
while (1) {
    mqtt_loop(); // 内部调用 MQTTYield(&c, 100);
}
```
