# W5500 第一阶段 Step 4：静态 IP 配置与寄存器对应（写进去=读得回）

目标：你能明确回答两件事：
- 我在代码里改了 IP/掩码/网关/MAC，W5500 最终写到了哪些寄存器？
- 我怎么验证“确实写进去了”（而不是我以为写了）？

本工程使用静态网络参数（`NETINFO_STATIC`）。

## 1. 你要改哪里（本工程入口）

网络参数定义在：
- [bsp_w5500.c](file:///i:/AI/w5500/BSP/bsp_w5500.c#L54-L58)

你最常改的字段：
- `.mac`
- `.ip`
- `.sn`
- `.gw`
- `.dns`
- `.dhcp`（静态/动态）

建议：
- MAC 尽量保证唯一（同网段 MAC 冲突会出现非常诡异的问题）

## 2. wiz_NetInfo 对应的寄存器（Common 寄存器块）

W5500 里这些都属于 Common Register Block（全局配置，不分 socket）。

| 字段 | 寄存器名 | 长度 | 说明 |
|---|---|---:|---|
| MAC | `SHAR` | 6 | Source Hardware Address Register |
| 网关 | `GAR` | 4 | Gateway Address Register |
| 子网掩码 | `SUBR` | 4 | Subnet Mask Register |
| 本机 IP | `SIPR` | 4 | Source IP Address Register |

寄存器宏位置：
- `SHAR/GAR/SUBR/SIPR`：[w5500.h](file:///i:/AI/w5500/BSP/w5500.h#L225-L246)

注意：
- DNS 不是 W5500 的硬件寄存器项，DNS 主要给 DNS/SNTP/HTTP 等上层库用（存放在软件结构体里）。

## 3. 写入路径：wizchip_setnetinfo() 实际做了什么

在本工程的 ioLibrary（BSP 版本）中：
- `wizchip_setnetinfo(&net_info)` 会按顺序写入 `SHAR/GAR/SUBR/SIPR`

代码位置：
- [wizchip_conf.c](file:///i:/AI/w5500/BSP/wizchip_conf.c#L1379-L1390)

## 4. 两种验证方式（推荐方式 A）

### 4.1 方式 A：读回结构体（推荐）

用：
- `wizchip_getnetinfo(&info)`

你现有的 `w5500_dump()` 已经做了这件事，并打印出来：
- [bsp_w5500.c](file:///i:/AI/w5500/BSP/bsp_w5500.c#L60-L77)

验收：
- 串口打印的 `MAC/IP/SN/GW` 与你写入的一致

### 4.2 方式 B：直接读寄存器（更底层）

当你想完全确认“寄存器里是什么”，用：
- `getSHAR()` / `getGAR()` / `getSUBR()` / `getSIPR()`（宏在 `w5500.h` 中）

如果你后面要做“阶段一一键自检”，方式 B 更适合做 PASS/FAIL。

## 5. 常见错误与现象对照表（非常实用）

| 错误 | 常见现象 | 快速证据 |
|---|---|---|
| IP 不在同网段 | ping 不通/ARP 不通 | PC `ipconfig` 看网段；板子打印 IP |
| 网关填错 | 访问外网不通，但局域网可通 | ping 网关失败或 traceroute 异常 |
| 掩码填错 | 局域网某些地址可通某些不通 | 同网段判断错误（ARP/路由异常） |
| MAC 冲突 | 一会儿能通一会儿不通 | 路由器客户端列表/抓包看到 MAC 抖动 |

## 6. Step 4 的验收（你做完要得到什么）

- 串口打印网络参数与预期一致
- PC 能 ping 通板子 IP
- `arp -a` 能看到板子 IP 对应 MAC
