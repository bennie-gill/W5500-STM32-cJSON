# W5500 第二阶段 Step 6：验收清单（UDP/TCP 跑通并可长期运行）

目标：把第二阶段成果变成一张清单，方便你每次改代码/改网参/改 SPI 频率后快速回归。

## 1. 前置条件（来自第一阶段）

- `VERSIONR=0x04` 稳定可重复
- `PHYLINK=1` 且 PC 能稳定 ping 通板子 IP
- `arp -a` 能看到板子 IP 对应真实 MAC

## 2. UDP 验收（建议端口 5000）

- 板子 UDP socket 状态为 `SOCK_UDP`
- PC 连续发送 100 次，回显 0 丢包
- Wireshark 中 `udp.port == 5000` request/reply 成对出现

## 3. TCP Server 验收（建议端口 5001）

- PC 能连接上板子（握手完成）
- PC 发数据，板子能 echo 回显
- PC 断开后，能再次重连（多次）
- Wireshark 中 `tcp.port == 5001` 能看到握手、数据、断开

## 4. TCP Client 验收（建议 PC 端口 5002）

- 板子能主动连上 PC
- PC 重启 server 后，板子能自动重连
- 抓包能看到板子发起 SYN，并完成握手

## 5. 可靠性验收（工程化）

- Link Down/Up：拔网线 10 秒插回，UDP/TCP 恢复
- 长时间运行：连续运行 30 分钟无卡死
- 状态机边界：不会长期卡在 `SOCK_CLOSE_WAIT` 或 `SOCK_INIT`

## 6. 排障捷径（出现问题先做这三条）

- 抓包：确认包到没到（Wireshark）
- 状态：打印 `getSn_SR(sn)`、`getSn_RX_RSR(sn)`（板子串口）
- 网卡：多网卡时用 `ping -S <源IP>` 或检查路由

通过本清单后，你就具备进入第三阶段（DNS/DHCP/SNTP/HTTP 或项目协议）的基础。
