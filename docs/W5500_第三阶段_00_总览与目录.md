# W5500 第三阶段：MQTT 通信应用 (00_总览与目录)

## 1. 阶段目标
在 W5500 完成静态 IP 及基础 TCP/UDP 通信的基础上，本阶段将实现基于 MQTT 协议的物联网通信。目标是使 W5500 能够连接到公共 MQTT Broker（如 EMQX），实现消息的订阅、发布，并能根据收到的指令进行数据回传。

## 3. 技术背景
- **协议版本**：MQTT v3.1.1
- **库文件**：Paho MQTT (由 WIZnet ioLibrary 提供接口封装)
- **底层支持**：W5500 硬件协议栈 (Socket 0 为例)
- **调试工具**：MQTTX (PC端)、Wireshark (抓包分析)
