# W5500 第三阶段：MQTT 通信应用 (06_排障手册与验收清单)

## 1. 常见问题排查

| 现象 | 可能原因 | 解决方法 |
| :--- | :--- | :--- |
| **MQTTConnect 失败** | W5500 无法访问外网 | 检查网关 (GW) 配置，确保能 Ping 通外网 IP。 |
| **连接后频繁掉线** | 定时器逻辑未正常工作 | 检查 `HAL_GetTick()` 是否在 `mqtt_interface.c` 中正确应用。 |
| **消息发布失败** | Socket 冲突 | 确保 MQTT 使用的 Socket 编号 (如 0) 未被其他应用 (如 Loopback) 占用。 |
| **收不到回传消息** | 订阅 Topic 不匹配 | 确保 MQTTX 订阅的主题 (如 `w5500/status`) 与 W5500 发布的主题完全一致。 |
| **MQTTX 连接不上** | 网络防火墙或代理 | 尝试关闭本地防火墙，或使用手机热点测试。 |

---

## 2. 核心状态码解析

| 状态码 | 含义 | 建议 |
| :--- | :--- | :--- |
| **SUCCESS (0)** | 连接成功 | 继续后续订阅/发布操作。 |
| **FAILURE (-1)** | 一般性错误 | 检查底层 SPI 通信和网络连接。 |
| **DISCONNECTED (-3)** | 已断开连接 | 尝试重新调用 `ConnectNetwork` 和 `MQTTConnect`。 |
| **TIMEOUT (-4)** | 操作超时 | 检查网络延迟，或者适当增加 `MQTTYield` 的超时时间。 |

---

## 3. 阶段验收清单 (Acceptance Criteria)

- [ ] **初始化**：W5500 成功获取 IP，并能通过 `w5500_dump` 打印正确的网络信息。
- [ ] **接口移植**：基于 `HAL_GetTick()` 的计时器正常工作，`w5x00_read/write` 已适配。
- [ ] **连接建立**：串口成功打印 `MQTT Protocol Connected!`。
- [ ] **订阅成功**：串口成功打印 `Subscribed to topic: w5500/control`。
- [ ] **数据接收**：MQTTX 发送消息后，W5500 串口能够实时打印收到的 Payload。
- [ ] **数据回传**：MQTTX 能够实时收到来自 W5500 (`w5500/status`) 的 Echo 消息。
